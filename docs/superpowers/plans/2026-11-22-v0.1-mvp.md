# chessmcp.org v0.1 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a live https://chessmcp.org where a Google-logged-in user gets a private MCP URL that renders an interactive SVG chess game/position inside ChatGPT.

**Architecture:** A pure-TS chess core (FEN, legal moves, SAN, PGN → list of positions) feeds a pure SVG renderer. A self-contained HTML widget (inlined JS, no external fetches) embeds the timeline and steps through it client-side. A Hono app serves the site, Google login (signed cookie) and a stateless streamable-HTTP MCP endpoint at `/mcp/:token`; the token is an HMAC of the user's Google `sub`.

**Tech Stack:** Bun 1.4, TypeScript (strict), Hono 4, `bun:test`, Docker, DO App Platform, Cloudflare DNS. No chess/SVG/PGN libraries. MCP implemented by hand (JSON-RPC over HTTP) or with the official `@modelcontextprotocol/sdk` (allowed: it is not a chess lib).

**Spec:** `/home/gilad/Work/chessmcp.org/chessmcp.md` (and `todo.txt`)

## Global Constraints

- Bun + TypeScript + Hono only for the server; own FEN/PGN/SVG code (no FEN2SVG / PGN2SVG libs).
- All visualization is SVG; pieces from lichess `public/piece/staunty` (attribution in footer; licence flagged to verify).
- No database; all secrets via env: `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `SESSION_SECRET`, `BASE_URL`, `PORT`. Local `.env` uses lowercase `google_client_id`, `google_client_secret`, `cf_token`; the config module reads either casing.
- Session: HMAC-signed, HttpOnly, Secure (https only), SameSite=Lax cookie with Google `sub` + email.
- MCP URL: `https://chessmcp.org/mcp/<token>`, token = `base64url(sub).base64url(HMAC-SHA256(SECRET, sub))`. No usage limits.
- ChatGPT only (MCP Apps `ui://` widget resource + text fallback in the tool result).
- Domain chessmcp.org (Cloudflare zone `2503ee8d537602413a9fa17c3453b624`); DO project `c68a3e88-a621-4aaa-80d5-396df5673897`; GitHub `chessmcp-org/web`.
- Google redirect URI path is `/login` (`https://chessmcp.org/login`, `http://localhost:3000/login`).
- Never commit `.env`.

## Review Focus

1. PGN with comments `{}`, `;` comments, NAGs (`$1`, `!?`), variations `( )`, and a result token: expected to parse the mainline and ignore the rest.
2. PGN with `[FEN]`/`[SetUp "1"]` header: the game starts from that position.
3. Illegal or ambiguous move in a PGN: a clear error naming the move number and SAN, not a crash. SAN disambiguation (`Nbd2`, `R1a3`), promotion (`e8=Q+`), castling (`O-O`, `0-0`), and en passant must all work.
4. Hostile text in PGN headers (`<script>`, `"`): must be escaped in SVG and HTML output.
5. Empty/whitespace PGN, multi-game PGN (use the first game), and very long games (500 plies): must respond fast and stay under the iframe payload limits.
6. Tampered or truncated MCP token / cookie, and a Google callback with a missing or wrong `state`: 401/400, never a logged-in user.

### Task 6: MCP server

**Files:**
- Create: `src/mcp/server.ts`, `src/mcp/tools.ts`
- Test: `src/mcp/mcp.test.ts`

**Interfaces:**
- Consumes: `parseGame`, `gameFromFen`, `renderWidgetHtml`, `verifyMcpToken`.
- Produces: `app.all("/mcp/:token", …)` handling JSON-RPC `initialize`, `tools/list`, `tools/call`, `resources/list`, `resources/read`, `ping` (stateless streamable HTTP, JSON responses; `GET` returns 405). Tools: `show_game({ pgn: string, ply?: number })` and `show_position({ fen: string })`. Each tool result has `content: [{type:"text", text: "<summary: players, result, N moves>"}]` plus `_meta["openai/outputTemplate"]` pointing at the widget resource, and `structuredContent` containing the game for the widget. Resource `ui://widget/game.html` (mime `text/html+skybridge`, the ChatGPT Apps SDK widget type) serves the widget shell, which reads its data from `window.openai.toolOutput` and falls back to embedded data. Invalid token → 401. Tool errors return `isError: true` with the `PgnError` message.
